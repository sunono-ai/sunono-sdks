# Sunono SDKs

Client SDKs for the [Sunono](https://sunono.ai) AI shopping assistant.

| Platform | Package | Status |
|---|---|---|
| Flutter | [`sunono`](flutter/) on pub.dev | beta (0.3) |
| React Native | `@sunono/react-native` | planned |
| Android (Kotlin) | `ai.sunono:sdk` | planned |
| iOS (Swift) | Swift Package (own repo) | planned |

All SDKs speak one wire contract, [**protocol v1.2**](protocol/PROTOCOL.md). They must pass the shared [conformance fixtures](protocol/fixtures/).
